Macam mana ia berfungsi?

Browser (Chrome/Safari) tidak dibenarkan membaca sensor suhu phone. Jadi ThermoCheck mengukur benda yang betul-betul buat game lag: thermal throttling.

Bila phone panas, sistem turunkan kelajuan CPU untuk sejukkan diri. ThermoCheck jalankan ujian CPU kecil setiap beberapa saat dan bandingkan dengan skor masa phone sejuk. 100% = laju penuh. Kalau jatuh ke 70%, phone anda sedang throttle, sebab itu game lag.

Cara guna untuk gamer
  • Sekali sahaja: bila phone sejuk (belum main, tak cas), tekan Kalibrasi. Baseline disimpan dalam phone.
  • Lepas main game: buka ThermoCheck. Bacaan terus keluar. Kalau <75%, rehatkan phone.
  • Browser pause tab bila anda buka game, jadi website tak boleh pantau semasa game berjalan. Semak sebelum dan selepas main, atau semasa rehat antara match.
  • Tekan Share → Add to Home Screen (iPhone) atau ⋮ → Install app (Android) supaya boleh buka macam app.
Tips kurangkan panas
  • Jangan main sambil cas, sebab cas adalah punca panas nombor 1.
  • Buka casing phone masa main lama.
  • Turunkan graphics / FPS dalam setting game (contoh 60 → 40 FPS).
  • Kurangkan brightness dan tutup app background.
  • Elak main bawah matahari atau atas tilam/bantal.
  • Guna phone cooler (kipas clip-on) untuk sesi panjang.
